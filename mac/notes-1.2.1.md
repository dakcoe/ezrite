## 받기
- macOS 13 이상: `Ezrite-1.2.1.dmg`
- Windows 10·11 (64비트): `Ezrite-Setup-1.2.1.exe`

## macOS
- Groq 로 설명할 때 그림 안내를 기존 네 가지(단계·표·카드·관계도)로 되돌렸습니다. 설명 한 번의 입력이 약 2,100 → 1,650 토큰으로 줄고 답도 짧아져, Groq 무료 한도(특히 qwen 분당 출력)에 덜 걸립니다
- 움직이는 그림(층·칸·그래프 포함)은 설정 → 기능별 AI 에서 화면 설명을 Claude·Gemini·GPT 로 고른 경우에만 나옵니다
- 화면 나누기, 요약 줄바꿈은 1.2.0 그대로입니다
- 작은 창을 화면 위 가장자리로 끌어 놓으면 가운데로 튕기던 문제를 고쳤습니다. 놓은 자리에 그대로 있고, 다음에 열 때도 거기서 뜹니다 (오른쪽 위 모서리에 두고 쓰기 좋게)

## Windows
- 1.1.5 다음 버전입니다 (1.2.0 은 macOS 만). 맥 1.2.0·1.2.1 의 바뀐 점이 한 번에 들어왔습니다
- 움직이는 그림: 설명과 질문 답에 상자가 나타나고, 자리를 바꾸고, 화살표로 신호가 흐르는 그림이 생겼습니다. 층(신경망·트리), 칸(행렬·표), 좌표 그래프(곡선 이동)도 그립니다. 질문 답의 그림은 저절로 재생되고 [↻ 다시] 로 다시 볼 수 있습니다. 설정 → 기능별 AI 에서 화면 설명을 Claude·Gemini·GPT 로 고른 경우에만 나옵니다 (Groq 는 기존 네 가지 그림)
- 설명할 때 화면 나누기: 설정 → 옵션 → "설명할 때 화면 나누기" (기본 꺼짐). 켜면 설명해줘를 누를 때 그 화면의 창들을 같은 비율로 왼쪽에 줄여 넣고 오른쪽에 설명 카드를 붙입니다. 카드를 닫으면 창이 원래 자리·크기로 돌아옵니다 (최대화했던 창은 다시 최대화). 전체 화면 창과 관리자 권한으로 실행한 창은 그대로 둡니다
- 설명 요약은 문장마다 줄을 나누고 첫 문장을 굵게 보여 줍니다. 질문 답도 긴 문단을 두 문장씩 나눕니다
