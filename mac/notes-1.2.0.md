- 설명 카드에 움직이는 그림: 정렬·흐름·신경망·행렬·그래프가 단계마다 움직이며 설명됩니다
- 설명할 때 화면 나누기: 창들을 왼쪽으로 줄이고 오른쪽에 설명 카드를 붙여 슬라이드를 가리지 않습니다
- 설명 요약을 한 문장에 한 줄로 정리해 보여 줍니다

## 받기
- macOS 13 이상: `Ezrite-1.2.0.dmg`

## macOS
- 움직이는 그림: 설명과 질문 답에 새 그림 형식이 생겼습니다. 상자가 나타나고, 자리를 바꾸고, 화살표로 신호가 흐릅니다. 층(신경망·트리), 칸(행렬·표), 좌표 그래프(곡선 이동·경사하강)도 그립니다. 질문 답의 그림은 저절로 재생되고 [↻ 다시] 로 다시 볼 수 있습니다
- 화면 나누기: 설정 → 옵션 → "설명할 때 화면 나누기" (기본 꺼짐). 켜면 설명해줘를 누를 때 그 화면의 창들을 같은 비율로 왼쪽에 줄여 넣고 오른쪽에 설명 카드를 붙입니다. 카드를 닫으면 창이 원래 자리·크기로 돌아옵니다. 처음 켤 때 손쉬운 사용 권한을 허용해야 합니다. 전체 화면 창은 그대로 둡니다
- 설명 요약은 문장마다 줄을 나누고 첫 문장을 굵게 보여 줍니다. 질문 답도 긴 문단을 두 문장씩 나눕니다
