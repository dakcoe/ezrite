- 화면 테마(시스템 / 밝게 / 어둡게)와 로그인할 때 자동 실행을 설정에 넣었습니다
- 번역이 한 줄씩 밀리던 문제와 말이 단어 가운데서 잘리던 문제를 고쳤습니다

## 받기
- macOS 13 이상: `Ezrite-1.1.0.dmg`
- Windows 10·11 (64비트): `Ezrite-Setup-1.1.0.exe`

## Windows (첫 공개)
- 작업 표시줄 오른쪽 ^ 안의 Ezrite 아이콘에서 강의 소리를 받아 적고 한국어로 옮깁니다
- 크롬·줌 같은 프로그램 소리(Windows 11) 또는 마이크로 받고, 글과 녹음을 저절로 저장합니다. Windows 10에서는 마이크로만 받습니다
- ✨ 설명해줘: 화면을 읽어 ①②③으로 짚어 설명하고, 이어서 물어볼 수 있습니다 (무료 Groq 키 필요)
- 서명 없는 빌드라 설치할 때 "Windows의 PC 보호"가 뜹니다. [추가 정보] → [실행]을 누르세요

## macOS
- 12초 넘게 쉬지 않고 말할 때, 마지막 1초 안의 가장 조용한 곳에서 끊습니다. 단어가 두 조각으로 잘려 틀리게 받아 적히던 일이 줄어듭니다
- 앞 줄이 문장 중간에서 끊겼을 때 번역이 한 줄씩 밀려 앞 줄 번역이 다시 붙던 것을 고쳤습니다
- 설명 답에 "(0번 화면)", "25번 화면" 같은 내부 번호가 남던 것을 지우거나 그 줄의 글자로 바꿉니다
- 설정에 "화면 테마"(시스템 설정 따르기 / 밝게 / 어둡게)를 넣었습니다
- 설정에 "로그인할 때 자동 실행"을 넣었습니다 (기본은 꺼짐)
