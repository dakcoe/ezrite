안전과 안정성을 다듬은 버전입니다.
기록 지우기·업데이트 받기·설치 정리가 더 안전해졌고, 다시 받아 적는 중에 기록이 꼬이던 문제를 막았습니다.
사용 가이드의 아이콘을 오픈소스 아이콘(Lucide)으로 바꿨습니다.

## 바뀐 점
- 이름에 역슬래시(\)나 따옴표가 든 기록도 휴지통으로 옮길 수 있습니다
- 새 버전 [받기] 는 GitHub 주소만 엽니다
- 설치 DMG 를 자동으로 꺼낼 때, 이름이 비슷한 외장 디스크는 건드리지 않습니다
- DMG 나 내려받은 폴더에서 바로 켜도 "Applications 로 옮기세요" 안내가 뜹니다
- 다시 받아 적는 중에는 그 기록의 이름 바꾸기·지우기를 막아, 기록이 되살아나거나 둘로 갈라지지 않습니다
- 사용 가이드 아이콘을 Lucide(ISC) 로 바꾸고 오픈소스 고지에 넣었습니다
