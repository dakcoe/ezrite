- Claude Sonnet 5.5 를 고르면 "쓸 수 없음"이 뜨던 문제를 고쳤습니다
- 화면 설명에 Claude Opus 5.5 도 고를 수 있습니다
- 모델 목록에 Claude 의 최신판만 보입니다
- 일부 맥에서 설명해줘가 "CRImageReaderError" 오류로 멈추던 문제를 막았습니다
- 녹음을 끝내고 바로 [기록 보기]로 들어가면 소리가 00:00 으로 안 불러와지던 문제를 고쳤습니다
- [기록 보기]를 누르면 "저장됨" 띠가 사라집니다

## 받기
- macOS 13 이상: `Ezrite-1.1.4.dmg`
- Windows 10·11 (64비트): `Ezrite-Setup-1.1.4.exe` (서명 없는 빌드라 설치할 때 "Windows의 PC 보호"가 뜨면 [추가 정보] → [실행])

## macOS
- Claude Sonnet 5.5 가 키 확인과 번역·설명 요청을 거절해 "쓸 수 없음"으로 나오던 문제를 고쳤습니다. 생각 단계를 끄는 방식을 모델마다 맞춰 보냅니다
- 화면 설명 모델 목록에 Claude Opus 5.5 를 넣었습니다. 기본은 그대로 Sonnet 5.5 입니다
- Claude 모델은 등급(Opus·Sonnet·Haiku)마다 최신판만 목록에 보이고, 4.6 같은 이전 버전은 숨깁니다
- 화면 글자 인식이 실패하면("CRImageReaderError 1") 그림을 다시 그려 한 번, 빠른 인식으로 한 번 더 해 봅니다. 그래도 안 되면 멈추지 않고 화면 표시 없이 설명합니다
- 업데이트하지 않은 macOS 13 에서 설명 카드가 비어 보일 수 있던 문제를 막았습니다. 그림(흐름도)을 못 그려도 설명 글은 보입니다
- 녹음을 끝내자마자 기록을 열면 소리를 합치는 중이라 재생 막대가 00:00 에 멈추고 줄 재생도 되지 않던 문제를 고쳤습니다. 합치기가 끝나면 열려 있는 기록이 소리를 바로 불러옵니다
- "녹음 기록 저장됨" 띠에서 [기록 보기]를 누르면 띠가 사라져 설정 화면 등에서 다시 뜨지 않습니다

## Windows
- Claude Sonnet 5.5·Opus 5.5 가 번역과 키 확인에서 "쓸 수 없음"으로 나오던 문제를 고쳤습니다. 생각 단계를 끈 요청을 모델이 거절하면 그 모델이 받는 방식으로 다시 보냅니다
- 화면 설명에 Claude Opus 5.5 도 고를 수 있습니다 (기본은 Sonnet 5.5). Claude 모델은 등급마다 최신판만 보입니다
- 화면 글자 인식이 실패해도 설명이 나옵니다 (①②③ 표시만 빠집니다)
- "녹음 기록 저장됨" 띠에서 [기록 보기]를 누르면 띠가 사라집니다
