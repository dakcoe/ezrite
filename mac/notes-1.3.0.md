- 설명해줘의 화면 표시를 고를 수 있습니다 (설정 → 설명 표시 방식, 13가지). 기본은 "발자취": 번호는 설명 순서 하나만 뜻하고, 지난 장면은 회색 번호로 남아 끝나면 복습 지도가 됩니다
- "설명할 때 화면 나누기"를 없앴습니다. 창 너비만 줄여서 웹페이지 오른쪽이 잘리던 문제 때문입니다. 대신 설명 카드가 화면 글자를 가장 적게 가리는 자리에 뜹니다
- 설명 카드를 접을 수 있습니다. 접으면 지금 자막만 남고, 다시 펼치면 원래 크기로 돌아옵니다

## 함께 고친 것
- 카드에 질문하면 답 글이 오는 대로 바로 보입니다 (다 받을 때까지 기다리지 않음)
- 답을 읽지 못하면 저절로 한 번 더 묻습니다. 수식이 많은 답이 중간에 잘리던 것을 고쳤습니다 (토큰 한도 8000)
- 답에 "8번 줄" 대신 그 줄의 글자를 씁니다. `\nabla`·`\neq` 같은 수식이 깨지던 것, 카드보다 넓은 수식이 넘치던 것을 고쳤습니다
- 설명 카드는 질문 칸을 누를 때만 키 입력을 가져갑니다. 맥에서 뒤의 브라우저가 키를 받던 문제(유튜브가 f 마다 전체 화면을 오가던 것)도 고쳤습니다
- 기록 화면이 새 줄을 따라 내려가다 멈추던 것을 고쳤습니다. 녹음 팝업과 설명 카드가 겹치면 누른 쪽이 앞에 옵니다

## 설명 표시 방식
- 지금 하나만: 스포트라이트 · 형광펜 · 모서리 괄호
- 카드와 짝: 카드에 마우스를 올린 곳만 · 색으로 짝 맞추기 · 카드에서 잇는 선
- 순서를 남기기: 흐르는 점 · 발자취 · 카드 속 지도
- 화면에 바로 적기: 말풍선 · 여백 메모 · 판서 (장면마다 짧은 꼬리표를 AI 에게 함께 받습니다)
- 예전 주황·파랑 상자는 "상자와 번호 (예전 방식)" 으로 남아 있습니다

## Windows
