- 화면 번역 (실험 기능): 설정 → 실험 기능 → "화면 번역" 을 켜면 팝업에 번역 단추가 생깁니다. 누르고 창을 고르면 그 창의 글자를 한국어로 옮겨 원래 줄 자리에 덮습니다
  - 앞뒤 문장과 화면의 다른 글을 함께 보고 옮깁니다. 제목·목차·단추 글자도 옮기고, 코드·주소·숫자는 그대로 둡니다
  - 스크롤하거나 내용이 바뀌면 새 줄만 다시 옮깁니다. 한 번 옮긴 줄은 기억해 두었다가 다시 보이면 바로 덮습니다
  - 줄에 마우스를 올리면 원문이 보입니다. 창 고르기는 Esc 나 오른쪽 클릭으로 취소합니다
  - 창 위쪽 도구 막대에 걸려 잘린 문단은 옮기지 않고, 다 보이면 그때 옮깁니다
  - 켜 둔 동안 고른 창의 글자가 번역 AI 로 계속 전송됩니다. Groq 와 Claude 에서 확인했습니다
- 업데이트 띠·저장 완료 띠가 창을 위로 늘리지 않고 창 안에 떠서 나타납니다
- 앱 기록을 남깁니다 (`~/Library/Logs/Ezrite`). 버그를 다시 찾을 때 씁니다. 받아 적은 글·화면 글·번역 글·API 키는 남기지 않고, 개수·길이·걸린 시간만 남깁니다. 14일 지난 기록은 지웁니다
- 앱이 멈추면 그 순간의 상태를 기록 폴더에 한 장 남깁니다

## 받기

- Windows 10·11: `Ezrite-Setup-1.3.2.exe`
- 1.2.4 이후 버전을 쓰고 있다면 새 버전 띠의 [업데이트] 로 바뀝니다

## Windows
- 처음 올린 1.3.2 설치 파일(11-27 05시 무렵 받은 것)은 켜지지 않았습니다. 그 파일로 설치했다면 이 릴리스의 설치 파일을 다시 받아 설치해 주세요 (기록·키·설정은 그대로입니다)
- 앱 기록 위치: `%LOCALAPPDATA%\Ezrite\logs\ezrite-YYYY-MM-DD.log` (14일 지난 기록은 지웁니다)
- 앱이 멈추면 그때의 상태를 같은 기록 폴더에 남깁니다. 창(화면) 쪽이 멈춘 경우에는 멈췄다는 사실과 시간만 남습니다
- 화면 번역은 Windows 에 들어 있는 글자 인식(OCR)으로 읽습니다. 영어 인식 언어 팩이 없으면 기본 인식으로 읽어 영어 글자를 가끔 잘못 읽습니다 (처음 한 번 알려 줍니다). 설정 → 시간 및 언어 → 언어 및 지역에서 English 를 추가하면 더 정확합니다
- 화면 번역은 고른 창만 찍으므로 다른 창이 그 위를 가리면 번역 덮개를 잠시 숨깁니다
- Windows 에서는 화면 번역을 Groq 로 확인했습니다 (Claude 길은 시험 응답으로만 확인)
