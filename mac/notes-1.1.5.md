- 말소리가 30초 동안 없으면 자동으로 잠시 멈추고, 다시 들리면 같은 기록에 이어서 녹음합니다

## 받기
- macOS 13 이상: `Ezrite-1.1.5.dmg`
- Windows 10·11 (64비트): `Ezrite-Setup-1.1.5.exe` (서명 없는 빌드라 설치할 때 "Windows의 PC 보호"가 뜨면 [추가 정보] → [실행])

## macOS
- 조용하면 자동 일시정지: 말소리가 30초 동안 없으면 "조용함 · 자동 일시정지"로 바뀌고, 그동안은 녹음 파일에 넣지 않습니다. 말이 다시 들리면 첫 음절부터 같은 기록에 이어서 녹음하고, 쉰 자리를 기록에 표시합니다. 설정 → 옵션에서 끌 수 있습니다 (기본 켬)

## Windows
- 말소리가 30초 없으면 녹음을 저절로 쉬고, 말이 다시 들리면 이어서 녹음합니다. 쉬는 동안 시계가 멈추고 머리에 "조용함 · 자동 일시정지"가 보이며, 이어 갈 때 기록에 쉰 구간 줄이 남습니다. 쉰 구간은 녹음 소리에 들어가지 않고, 기록에서 줄을 눌러 들으면 제자리가 재생됩니다
- 설정 → 옵션 → "조용하면 자동 일시정지" (기본 켜짐). 녹음 중에 끄면 바로 이어서 녹음합니다
