## 받기
- macOS 13 이상: `Ezrite-1.2.4.dmg`
- Windows 10·11: `Ezrite-Setup-1.2.4.exe`
- 이번 한 번만 직접 받아 설치해 주세요. 그다음 버전부터는 앱 안에서 바뀝니다

## macOS
- 자동 업데이트: 새 버전 띠의 [업데이트] 를 누르면 앱이 새 버전을 직접 받아, 지금 앱과 같은 서명인지 확인한 뒤 바꿔 끼우고 다시 켭니다. 녹음 중에는 바꾸지 않습니다. 안 되면 [브라우저로 받기] 가 뜹니다. 마이크·화면 녹화 권한은 그대로 남습니다. 1.2.4 를 설치한 뒤 나오는 버전부터 적용됩니다
- 설명 프롬프트: 교수님이 한 말을 다시 옮겨 적지 말고, 화면의 무엇을 가리키는지와 왜 그런지를 설명하게 했습니다
- 앱을 켤 때 정리하며 지운 파일(글 없이 남은 소리 등)의 이름을 시스템 로그에 남깁니다
- 움직이는 그림의 상자가 좁으면 한글이 한 자씩 줄바꿈되던 것을, 상자를 여러 줄·위아래로 배치해 고쳤습니다

## Windows
- 자동 업데이트: 새 버전 띠의 [업데이트] 를 누르면 앱이 설치 파일을 직접 받아 조용히 설치하고 다시 켭니다. SmartScreen 경고가 뜨지 않고, 키·기록·설정은 그대로입니다. 녹음 중에는 설치하지 않습니다
- 설명이 교수님 말을 되풀이하지 않게 맥과 같은 프롬프트로 바꿨습니다
- 아래쪽 비용 표시를 맥과 같게 맞췄습니다 (0.01 달러 미만은 소수 셋째 자리까지)
