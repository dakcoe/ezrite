# Study AI

강의 소리를 받아 적고, 영어·일본어 강의는 한국어로 옮기고, 모르는 장면은 AI 가 화면을 보고 짚어 가며 설명해 주는 macOS 메뉴바 앱입니다.

## 받기

[최신 버전 내려받기 (DMG)](https://github.com/dakcoe/study-AI/releases/latest)

1. DMG 를 열고 `Study AI` 를 `Applications` 폴더로 끌어 넣습니다.
2. 처음 열 때 "확인되지 않은 개발자" 창이 뜨면 DMG 안의 `설치 안내.txt` 를 따라 주세요.
3. 앱이 안내하는 대로 무료 Groq 키를 넣고, 마이크·화면 녹화 권한을 허용합니다.

새 버전이 나오면 앱이 알려 줍니다.

## 할 수 있는 것

- 메뉴바에서 바로 녹음 — 시스템 전체 소리, 특정 앱(크롬·줌 등), 마이크
- 실시간 받아쓰기와 번역, 줄마다 그 부분 소리만 다시 듣기
- ✨ 설명해줘 — 지금 화면을 짚어 가며 장면별로 설명하고, 이어서 질문
- 지난 기록 — 이름 붙이기, 내보내기, 저장 위치(iCloud 등) 바꾸기

무료 Groq 키 하나면 됩니다. Claude·Gemini·GPT 키는 넣고 싶을 때만 넣으면 됩니다.
키와 기록은 내 Mac 에만 저장됩니다.

## 요구 사항

macOS 14 이상 · Apple 칩과 Intel 모두 지원
